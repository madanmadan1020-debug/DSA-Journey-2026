# LeetCode #1 - Two Sum

## Problem

Find the indices of two numbers such that they add up to the target.

## Approach

- Used the brute-force approach.
- Compared every pair of elements using nested loops.
- Stored the indices in dynamically allocated memory using `malloc`.
- Returned the result immediately after finding the pair.

## Time Complexity

O(n²)

## Space Complexity

O(1)

## Concepts Learned

- Nested loops
- Dynamic memory allocation (`malloc`)
- Pointers
- Returning dynamically allocated arrays
- Understanding `returnSize` in LeetCode
